# Bella小朋友专属注意力训练APP（PWA）

## 在线地址
https://reid-zhou.github.io/focus-trainer/

## 手机安装
- **安卓 Chrome**：打开上方链接 → 菜单 → **「安装应用」**
- **iOS Safari**：打开上方链接 → 分享 → **「添加到主屏幕」**

安装后主屏会出现 **「Bella专注力」** 图标，点开即可**全屏、离线**运行。
